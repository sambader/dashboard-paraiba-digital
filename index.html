Configuração inicial
Informe os dados do seu repositório GitHub para que o dashboard possa ler e salvar os dados automaticamente. Essa configuração é feita uma única vez e fica salva no navegador.

Nome exato do repositório criado no GitHub
Normalmente main ou master
Acesse GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
Crie um token com permissão public_repo.
O token fica salvo apenas no seu navegador e nunca é enviado a servidores externos.
